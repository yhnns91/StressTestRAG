# Code of Conduct

## Our commitment

This project is a research collaboration. Everyone involved is expected to
contribute in a way that is respectful, evidence-based, and honest about
uncertainty.

## Expected behaviour

- Give and receive review comments on the work, not the person.
- State disagreement with evidence: condition, evidence, impact, options, recommendation.
- Report problems early. A blocked task raised on day one costs less than a
  silent one raised on day ten.
- Acknowledge uncertainty rather than filling gaps with assumption.
- Respect the content exclusions defined in `README.md` without exception.

## Unacceptable behaviour

- Harassment, personal attacks, or discriminatory language.
- Fabricating data, sources, checksums, or annotation labels.
- Overwriting or deleting another contributor's work without discussion.
- Committing credentials, personal data, or restricted material.

## Reporting

Raise concerns with the project supervisor. Issues involving data integrity
should additionally be filed as a GitHub issue labelled `needs-review`.
